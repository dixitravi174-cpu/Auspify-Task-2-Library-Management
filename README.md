# Task 2: Library Management System

A web-based Library Management System developed using **Python (Flask)** and **SQLite3** for the Auspify Technologies Software Development Internship.

---

## 📌 Project Overview
The application provides complete CRUD (Create, Read, Update, Delete) functionality to manage a digital catalog of library books, track their availability status, and organize them by categories.

### ✨ Features
- **Add New Book**: Enter book title, author name, ISBN, and category.
- **View Inventory**: Live tabular display of all books with IDs and statuses.
- **Update Record / Status**: Inline updating of book metadata and quick toggling between `Available` and `Issued`.
- **Delete Book**: Secure deletion of book records with confirmation alerts.
- **Persistent Storage**: Lightweight SQLite3 database.

---

## 🛠️ Tech Stack
- **Backend**: Python 3.12, Flask
- **Database**: SQLite3
- **Frontend**: HTML5, CSS3, Bootstrap 5, Jinja2 Templates
